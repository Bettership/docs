## What to do

Open the view marked as needing attention and read its explanation. If **Summary** says an earlier step failed, check **Article** or **Transcript** for the original problem and its **Retry** button. Choose **Retry** to start another attempt. It doesn't guarantee the underlying access or processing problem is resolved.

You can also ask Scout, “The summary for this article failed. Can you retry it?” Scout can tell you which work restarted. Check the page for the result.

If the material couldn't be read, check the original link or file. A private page, unavailable transcript, or missing saved input may need a different way of bringing it in.

If **Article** says the page wasn't fully captured, saving the link or seeing a summary doesn't mean Bettership has the full text. Where you have permission, a file upload can give Bettership the material the link couldn't provide.
