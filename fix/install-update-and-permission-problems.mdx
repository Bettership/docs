## If the installer doesn't open

If the installer doesn't open or macOS reports a problem with it, keep the exact message and see [Contact support](/fix/contact-support). Don't work around an unexpected security warning to get past it.

## Check for an update

The installed desktop app checks for updates and downloads an available update. Once an update is ready, the app offers a restart to install it.

Check the installed version and available update controls in **App preferences**. Finish or otherwise resolve any active capture before restarting.
