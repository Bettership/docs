A Focus Area names what you're getting better at, so every agent works toward the same goal.

Say you're preparing for a promotion to engineering manager. Without a Focus Area, Scout and Coach each guess at what matters. With one, both start from the goal you wrote.

## One goal at a time

Each Focus Area holds one goal in your own words. You cannot give two Focus Areas the same name.

Words that only look like agent names stay lowercase where they belong: the address `/agents/scout`, the path docs/agents/coach.md, the link https://docs.bettership.ai/agents/maker, and a code span such as `steward; scout`.

```
coach; maker -- a fenced block is skipped too
```

## Shared by every agent

Steward, Scout, Coach, and Maker all read it. Start with [Add a resource to fill a Focus Area](/learn/add-a-resource), or open [Learn with Scout](/agents/learn-with-scout).
