Add something you want to learn from so you can return to it, discuss it with an agent, and connect it to other material in your Library.

## Choose how to bring it in

Open **Add resource** in the desktop app, then choose a tab.

### Link

Paste the link to a web page, article, social post, podcast episode, or video. Choose **Add resource**.

For a podcast, use a link to the episode you want, rather than the show's home page. A link that works in your signed-in browser may still need access Bettership doesn't have.

### File

Choose or drop a file into the form. The picker lists the supported formats, including PDFs, Word documents, presentations, images, text, Markdown, transcripts, and audio or video files. Choose **Add resource**.

### Note

Give the note a title and paste or write its text. Choose **Add resource**. This creates a resource in the Library, separate from a note attached to an existing resource.

### Book

Enter a title, ISBN, or link. Matching books appear as you type. Select the correct title and author, check the **Add this book?** details, then choose **Add resource**. Use **Back** if the match is wrong. A book record isn't a promise that Bettership has the full text of the book.

Each tab offers **+ Collection** if you want to group the resource as you add it.

## Or ask an agent

You can ask Scout to add a link by including it in your message. For a book, include the title and author. Check any selection or confirmation card Scout presents. To save your own text as a resource, use the **Note** tab.

Files and anything that needs access on your computer use the desktop app. A file attached to a chat is conversation context until you choose to add it to the Library.

## Check the result

After saving, the **Resource added** message offers **Open resource**. You can also find the item in your Library. Its content, summary, and Scout's report may become available at different times. If a step fails, use the explanation on that resource rather than repeatedly adding the same item.
