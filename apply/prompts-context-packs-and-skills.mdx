Maker creates prompts, context packs, skills, and subagents you can carry into your own AI tools.

## Made items have files

A reusable prompt carries instructions you can use again. A context pack gives another AI tool relevant background. A skill packages an approach you want that tool to follow.

Each item has its own page in **Apply → Studio**, with the resources it drew on, its revised versions, and its files. Its **Download files** button gives you the files and use instructions, to take the work elsewhere for personal use.

Downloading files doesn't install them in another tool. You still place or attach them there and follow the instructions for that tool. Maker can explain the steps. The one thing the desktop app installs for you is a subagent, below.

## A subagent is a specialist

A skill is one method. A subagent is a specialist built from your learning that knows which of its skills to use for what: a role, the skills it uses, and only the background it needs, packaged together. A startup advisor might pressure-test a plan with one skill and turn a growth idea into a first step with another.

AI tools take a subagent in different ways. Claude Code, Cursor, and Codex run it as a separate subagent once its install file for that tool is in the tool's agents folder. The desktop app puts it there once you turn on that tool's switch, such as **Claude Code**, under “Install subagents into tools on this computer” in **Settings → Connectors & MCP**. The subagent's page then reads “Installed in Claude Code.” A subagent made for your AI tools is published as soon as Maker finishes it. The app keeps the file up to date, takes it out if you unpublish the subagent or turn the tool off, and never changes a copy you've edited. You can also save the file yourself: the subagent's README names each folder. Claude chat and ChatGPT take on its role for one conversation when you ask for it by name, once they're connected to Bettership as [Use what you made in your AI tools](/apply/use-what-you-made-in-your-ai-tools) shows. An always-on agent, such as Grok Bot, takes the role pasted into its instructions. On the subagent's page, under “Where it works,” **Copy role for Grok Bot** copies it. When the agent is connected to Bettership, it keeps loading the subagent's current skills, while the pasted text changes only when you paste it again. “Where it works” lists all these ways.

## Personal use has a boundary

“Yours to keep for personal use” doesn't give you ownership of someone else's book, course, or method. Keep the rights attached to the original material in mind when using or sharing an output.

## A made item isn't an account export

Downloading Maker's files is different from taking a copy of all the personal data in your Bettership account. A self-service account export isn't available yet. You can request a copy by emailing [privacy@bettership.ai](mailto:privacy@bettership.ai).
