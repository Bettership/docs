A collection brings related resources together so you can find and use them as a group.

## Create a collection

1. Open **Learn → Collections**.
2. Choose **Add collection** and keep the **Collection** tab selected.
3. Enter a name. Add a description if it helps explain what belongs there.
4. Open **Additional details** if you want a cover image or your own label, such as “Reading list.”
5. Choose **Add collection**.

The same dialog has **Course** and **Publication** tabs for those kinds of material. A publication you follow has its own collection, with arrivals handled through the Inbox.

## File a resource

1. Open the resource and choose **+ Collection** beneath its details.
2. Select the collection you want. You can select more than one.
3. Choose **Add**, which shows the number selected, such as **Add (1)**.

The collection then appears beneath the resource's title. Select its name to open the collection and check the resource is there. You can also choose a collection while adding a new resource.

Grouping resources doesn't replace the originals. The collection gives you a way to work with them together.

## Or ask Scout

Name the collection and the resources you want to put in it. For example:

> Create a collection called Interview practice and put these two resources in it.

Scout can create and edit manual collections, add or remove resources, and archive or restore a collection when you ask. It doesn't reorganize the Library on its own.

Scout can reuse artwork already in Bettership. To use artwork from a web address, add it from the collection page yourself.

## Collection or Focus Area?

A collection groups material. A Focus Area names something you want to get better at. A course can be a collection, while asking better interview questions is the Focus Area you're learning toward.

**Try it:** Create one collection for material you already want to use together.
