Bettership's capture features need permissions from macOS. The desktop app shows their current status so you can check what needs attention.

## Install and open Bettership

Use the Bettership installer and instructions supplied with your invitation, then open the Bettership desktop app and sign in.

If the installer doesn't open or macOS reports a problem with it, keep the exact message and [contact support](/troubleshooting/getting-help). Don't work around an unexpected security warning just to get past it.

## Check capture permissions

1. Open **Settings → App preferences**.
2. Find **System permissions**.
3. Check the **Microphone** and **Screen Recording** rows.
4. Use **Open System Settings** beside the permission you need to change.
5. Follow the macOS prompt. If it asks you to quit and reopen Bettership, do so before trying again.

Microphone access covers audio from your microphone. Screen Recording access is used for system capture, including computer audio and capture images. **Watch window** lets you select which window to watch during a capture.

Granting access is your action in macOS. Steward can explain the steps but cannot approve permissions for you.

## Check for an update

The installed desktop app checks for updates and downloads an available update. Once an update is ready, the app offers a restart to install it.

Check the installed version and available update controls in **App preferences**. Finish or otherwise resolve any active capture before restarting.
